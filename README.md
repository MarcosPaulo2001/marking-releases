# MarKing

Instalador do **MarKing**.

O app instalado procura atualizações aqui sozinho. Quando sai uma versão nova, ele baixa em segundo plano e avisa para reiniciar.

---

## Baixar

| | |
|---|---|
| **Última versão** | [Releases →](https://github.com/MarcosPaulo2001/marking-releases/releases/latest) |
| **Sistema** | Windows 10/11 · 64 bits |
| **Arquivo** | `MarKing Setup x.y.z.exe` |

1. Abra a [última release](https://github.com/MarcosPaulo2001/marking-releases/releases/latest)
2. Baixe o instalador `.exe`
3. Instale e abra o MarKing
4. Entre com a conta MarKing e adicione a conta do jogo

Nas próximas versões, o próprio app atualiza — não precisa voltar neste repositório.

---

## Atualização automática

Com o app aberto (ou ao fechar, se você ignorou o aviso):

1. Detecta a versão nova neste repositório
2. Baixa o instalador em segundo plano
3. Mostra **Reiniciar para atualizar** no lançador
4. Instala e abre de novo

Se você fechar sem reiniciar, a atualização entra na próxima abertura.

---

## Requisitos

- Windows **64 bits** (x64)
- Conta MarKing com acesso liberado para a conta do jogo
- Internet (login, ticket de acesso e atualizações)

---

## Problemas?

- Instalador não abre → rode como administrador ou desative o bloqueio do SmartScreen (Mais informações → Executar mesmo assim)
- App não atualiza → confira se a versão instalada é menor que a da [última release](https://github.com/MarcosPaulo2001/marking-releases/releases/latest)
- Login / acesso → a API precisa estar no ar; o app usa o endereço configurado na build
